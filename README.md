# lemonsqueezy-billing

An Orunbase starter baseline, being built: Lemon Squeezy's
[Next.js Billing App](https://github.com/lmsqueezy/nextjs-billing) (MIT ©
2023 Lemon Squeezy, LLC) — GitHub sign-in through Auth.js, plans, checkout
and subscriptions over Lemon Squeezy, Drizzle over Postgres — on Cloudflare
Workers with a Supabase project's Postgres through Hyperdrive, provisioned by
Terraform through [Orun](https://github.com/sourceplane/orun).

The design, the milestones and the as-built status are in
[`specs/epics/lemonsqueezy-billing`](specs/epics/lemonsqueezy-billing/README.md).
`ci.yml` plans nothing while `intent.yaml` names the placeholder workspace
`ws_CHANGE_ME`.
